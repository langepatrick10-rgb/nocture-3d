# Nocture : 3D

A 3D piano for Windows. Play MIDI files, search songs online, drop in MP3s to transcribe, and practice on a concert or marble grand.

## Install (Windows)

Friends only need the installer — not this source code.

**[Download Nocture-3D-Setup.exe](https://github.com/langepatrick10-rgb/nocture-3d/releases/latest/download/Nocture-3D-Setup.exe)** (~530 MB)

1. Double-click the file.
2. If Windows says *Windows protected your PC*, choose **More info** → **Run anyway**.
3. A **Nocture 3D** shortcut appears on the desktop and in the Start menu. No admin password needed.

Or grab it from the **[Releases](https://github.com/langepatrick10-rgb/nocture-3d/releases/latest)** page.

## Playing

- Drop `.mid` or `.mp3` files onto the window
- **Song Hall** searches built-in pieces and online MIDI
- **Notes** is the falling-note practice view

## Uninstall

Settings → Apps → **Nocture 3D**, or right-click the Start menu shortcut and uninstall.
